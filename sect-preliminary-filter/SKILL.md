# 题记分字段准入

读取 [详细规则](references/detailed-rules.md)，区分任务排除、材料性质与判定证据。先评估原刻、已有题材及补充说明各自可用的内容，再分别决定主体识别与传统关联的准入。

工匠署名、供养题名、修装记及残损文字不自动退出分析。主体可确定而传统未定时，保留主体与未决原因。明确要求不处理的任务指令仍应遵守；资料中的“存目”“仅记录”等描述不自动成为对当前任务的禁令。

按 [输出规范](references/output-format.md)记录字段可用性、材料状态和可进入的分析层。之后进入 [宗派主控](../sect-judgment-hub/SKILL.md)调用真实引擎并复核语境。引擎候选与最终结论分别保存；本Skill不自动删除输入或日志。
