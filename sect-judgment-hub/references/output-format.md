# 判读输出规范 2.4.1

本规范替代旧模板中的总分锁宗、主体不明不得判任何传统及概率化措辞。按[分字段准入](../../sect-preliminary-filter/references/detailed-rules.md)和[文献与语境规则](weighting-rules-v2.3.md)分别保存识别与解释；不要求为每条填满所有类别。

## 必要内容

- 原文编号、响应模型（未指定时留空），原始输入另存。
- 准入状态与材料状态；字段可用性和冲突。
- 主体：名称、依据字段、实际引文、原刻明示／据著录／候选状态。主体可保留原称，即使当前分类没有独立标签。
- 传统关联：有何具体证据、可支持到哪一层；无依据则未定，不因主体明确强填传统。
- 最终标签ID：仅含确定保留的标签；候选另存，不计入确定标签。
- 逐标签依据、未决原因，以及修改／撤去引擎候选的说明。
- 引擎调用、原始匹配和各卷分数另存；不手算替代、不跨卷加成一个“信任总分”、不把S解释成正确概率。

## 兼容标签

沿用已有卷号：1通用大乘（一般佛教保留类别）、2观音、3净土、4药师、5密教、6华严、7禅宗、9地藏、10弥勒、11三论、12唯识、13天台、14成实、15律、16三阶教。0总则与8区域不作为最终宗教标签。2、4、9、10承载主体／信仰体系，不是独立组织宗派。

未设置单独标签的主体仍在主体字段中保存；不要为了硬塞某卷而改变主体身份。1不自动附加到每个细分类别；采用它时说明一般佛教的直接依据和保留用途。
